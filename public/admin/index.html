06 · BACKUP & ACCESS

Backup ও নিরাপত্তা

আপনার ওয়েবসাইটের backup

সাইটের edit করা লেখা, catalogue, hours ও gallery তালিকা JSON file হিসেবে download করুন।

Admin login

Public hosting-এ দেওয়ার আগে server-এর ADMIN_USERNAME, ADMIN_PASSWORD ও SESSION_SECRET অবশ্যই বদলাতে হবে। Public server local demo password দিয়ে চালু হতে দেবে না।

Public URL

এই local admin URL: /admin/. Login না থাকলে editor data দেখা যায় না।
